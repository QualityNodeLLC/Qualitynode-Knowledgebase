# Access Control

Control who can access your servers and what they can do.

## Sub-User Management

Grant limited access to team members, moderators, or friends.

### Adding a Sub-User

1. Go to your server panel
2. Click **Users**
3. Click **Add User**
4. Enter their email address
5. Set permissions
6. Send invite

### Permissions

Control exactly what each user can do:

| Permission | Description |
|------------|-------------|
| Console | View and send console commands |
| Files | Access file manager |
| Backups | Create and restore backups |
| Database | Manage databases |
| Schedules | Create and edit schedules |
| Settings | Modify server settings |
| Startup | Change startup parameters |
| Users | Manage other sub-users |

### Permission Presets

- **Viewer** - Console and file view only
- **Moderator** - Console, files, limited settings
- **Administrator** - Full access except billing
- **Custom** - Choose specific permissions

## Removing Access

1. Go to **Users** in your server panel
2. Find the user to remove
3. Click **Remove**
4. Confirm removal

> [!IMPORTANT]
> Regularly review who has access to your servers. Remove access for anyone who no longer needs it.

## Activity Logs

Track who did what:

1. Go to **Activity** in your server panel
2. View recent actions by all users
3. Filter by user or action type

## Best Practices

- Use the principle of least privilege
- Regularly audit user access
- Remove inactive users
- Use strong passwords and 2FA
- Don't share your main account credentials
