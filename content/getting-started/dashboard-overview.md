# Dashboard Overview

The QualityNode dashboard is your central hub for managing all your game servers.

## Main Dashboard

When you log in, you'll see:

- **Server Overview** - Quick status of all your servers
- **Resource Usage** - CPU, RAM, and storage metrics
- **Quick Actions** - Start, stop, restart servers
- **Recent Activity** - Latest server events and logs

## Server Management Panel

Click on any server to access its management panel:

### Console
Live server console with command input. View real-time logs and execute commands directly.

### Files
Browser-based file manager for editing configs, uploading files, and managing your server data.

### Backups
Create, restore, and manage server backups. Configure automatic backup schedules.

### Settings
Server configuration options including:
- Server properties
- Startup parameters
- Resource allocation
- Network settings

### Players
View connected players, manage bans and whitelists, and moderate your community.

## Account Settings

Access your account settings to:

- Update profile information
- Manage billing and subscriptions
- Configure two-factor authentication
- View invoices and payment history
