# Installing Mods

Enhance your Satisfactory server with mods from the Satisfactory modding community.

## Overview

Satisfactory modding uses:
- **Satisfactory Mod Manager (SMM)** - Official mod loader
- **ficsit.app** - Official mod repository

## Installing the Mod Loader

<!-- TODO: Add mod loader installation steps -->

1. Enable modding support in your server settings
2. The mod loader framework installs automatically
3. Restart your server

## Adding Mods

<!-- TODO: Add mod installation steps -->

1. Browse mods at [ficsit.app](https://ficsit.app/)
2. Download compatible server mods
3. Upload to your server's mod folder
4. Restart the server
5. Players install matching mods via SMM

## Popular Mods

| Mod | Description |
|-----|-------------|
| SMART! | Quality of life building improvements |
| Refined Power | Additional power generation options |
| Pak Utility | Extended building and logistics |

## Client Requirements

All players must have matching mods installed via Satisfactory Mod Manager. Mismatched mods prevent connection.
