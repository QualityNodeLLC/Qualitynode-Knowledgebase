# Getting Started with Satisfactory

This guide covers the essential steps for setting up your QualityNode Satisfactory server.

<!-- TODO: Complete this article with full setup instructions -->

## Quick Start

1. Access your control panel and select your Satisfactory server
2. Configure your server settings in the **Startup** tab
3. Start your server
4. Claim the server in-game and set an admin password

## Initial Configuration

The first player to connect becomes the server administrator. Set up your server:

1. Launch Satisfactory and go to **Server Manager**
2. Add your server using the IP and port
3. Claim the server when prompted
4. Set an admin password

## Server Settings

Configure your server through the **Startup** tab or in-game server manager:

| Setting | Description |
|---------|-------------|
| Server Name | Displayed to players |
| Max Players | Concurrent player limit |
| Auto Save Interval | How often the world saves |

## Connecting

Players connect through the in-game Server Manager:

1. Open Satisfactory
2. Go to **Server Manager**
3. Click **Add Server**
4. Enter your server IP and port
5. Join with the server password
