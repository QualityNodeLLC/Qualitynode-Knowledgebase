# Getting Started with Valheim

This guide covers the essential steps for setting up your QualityNode Valheim server.

## Quick Start

1. Access your control panel and select your Valheim server
2. Configure your server name and password in the **Startup** tab
3. Start your server
4. Connect using the server IP and port

## Server Configuration

Configure your server through the **Startup** tab:

| Setting | Description |
|---------|-------------|
| Server Name | Displayed in the server browser |
| Server Password | Required for players to join |
| World Name | Name of your world save |

## Connecting

Players connect through the in-game server browser or by direct connection:

1. Open Valheim
2. Select **Start Game** > **Start**
3. Choose **Join Game** tab
4. Click **Add Server** and enter your IP:Port
