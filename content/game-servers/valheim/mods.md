## Overview

Valheim modding uses:
- **BepInEx** - The mod loader framework
- **Thunderstore** - Popular mod repository
- **Nexus Mods** - Alternative mod source

## Installing BepInEx

<!-- TODO: Add BepInEx installation steps -->

1. Download BepInEx for Valheim
2. Upload to your server via the Files tab
3. Extract and configure
4. Restart your server

## Adding Mods

<!-- TODO: Add mod installation steps -->

1. Download mods from Thunderstore or Nexus
2. Upload to the `BepInEx/plugins` folder
3. Restart your server
4. Players install matching client mods

## Popular Mods

| Mod | Description |
|-----|-------------|
| Valheim Plus | Quality of life improvements |
| Epic Loot | RPG-style loot system |
| Plant Everything | Enhanced farming |

## Client Requirements

Most Valheim mods require installation on both server and client. Ensure all players have matching mod versions.
