# Troubleshooting

Quick solutions to common issues.

## Server Won't Start

1. Check console for error messages
2. Verify configuration files are valid
3. Ensure you have enough resources
4. Try reinstalling the server

## Can't Connect

1. Verify the server is online
2. Check you're using the correct IP and port
3. Ensure any server password is correct
4. Check your game version matches the server

## Performance Issues

1. Monitor resource usage in dashboard
2. Consider upgrading your plan
3. Reduce view distance or player count
4. Remove unnecessary mods/plugins
