# Control Panel Guide

The QualityNode control panel gives you complete control over your game servers.

## Overview

When you select a server, you'll see the main control panel with:

- **Status Indicator** - Current server state (Online/Offline/Starting)
- **Quick Actions** - Start, Stop, Restart buttons
- **Resource Graphs** - Live CPU and RAM usage
- **Connection Info** - Server IP and port

## Navigation

### Console
Real-time server output and command input.

```
> help
> list
> say Hello everyone!
```

### Files
Web-based file manager:
- Browse server files
- Edit configuration files
- Upload/download files
- Create folders and organize files

### Databases
Manage MySQL databases (where available):
- Create new databases
- Import/export data
- Manage users and permissions

### Schedules
Automate server tasks:
- Scheduled restarts
- Automated backups
- Custom commands on timers

### Users
Manage sub-users:
- Grant limited access to team members
- Set specific permissions
- Revoke access when needed

### Backups
Full backup management:
- Create manual backups
- Configure automatic backups
- Restore from any backup point

### Network
Network configuration:
- View allocated ports
- Configure additional ports
- Manage firewall rules

### Startup
Configure server startup:
- Set startup parameters
- Configure Java flags (for Java games)
- Adjust resource allocation

### Settings
Server settings:
- Rename your server
- Reinstall server files
- Transfer ownership

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + Enter` | Send console command |
| `Ctrl + S` | Save file (in editor) |
| `Ctrl + /` | Toggle comment (in editor) |

> [!TIP]
> Use the search bar at the top to quickly find settings and options.
